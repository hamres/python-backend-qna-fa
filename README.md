### Python

سؤال‌ها و مسائل مربوط به زبان Python و مباحث مورد نیاز برای Backend Development.

### Django

موضوعات مربوط به Django مانند:

* Models
* ORM
* QuerySet
* Migrations
* Views
* Middleware
* Signals
* Custom User Model
* Management Commands
* Django Security

### Django REST Framework

موضوعات مرتبط با توسعه API مانند:

* Serializers
* Views
* ViewSets
* Routers
* Permissions
* Authentication
* Validation
* Pagination
* Filtering
* Throttling
* API Design

### FastAPI

سؤال‌ها و تجربیات مربوط به FastAPI که به مرور به پروژه اضافه خواهند شد.

موضوعاتی مانند:

* Token Rotation

* Cookie Security
* Session Management
* CSRF

### Authorization

موضوعاتی مانند:

* Permissions
* RBAC
* Role Management
* Access Control
* Object-level Permissions

### Database

### Security
